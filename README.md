# Python каждый день 🐍

Каждый день — новая небольшая задача по Python: условие, решение с объяснением
и проверки. Каждая задача лежит отдельным файлом в папке [`tasks/`](tasks/),
запустить её можно так:

```bash
python3 tasks/2026-10-24_palindrome.py
```

Если все проверки прошли, скрипт напечатает «Все проверки пройдены ✅».
